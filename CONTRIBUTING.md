# Contributing

Thanks for your interest in contributing to shirudo. Please see the [contribution guide](Documentation/contribute/contributing.rst) for instructions.

Shirudo is a complex project in which most contributions require a significant level of expertise in kernel and/or eBPF development. It has a high technical bar to contribute because it operates in such a critical area. For these reasons, if you are new to open source contributions or to eBPF, this is unlikely to be the best open source project to get involved with.

If you are new to Shirudo, before making your first PR, we recommend raising a concise GitHub Issue describing your proposed contribution, or participating in a GitHub discussion about it. Reviewing contributions takes effort, so please bear in mind that Maintainers are under no obligation to review or give feedback on issues, PRs and discussions.

## AI contributions

All contributions must be associated with GitHub account that represents a human. As a human contributor you may use AI tools, but you are expected to take personal responsibility for the content, in the same way as if you authored the content without using any AI tools.

## DCO and Licensing

The Developer Certificate of Origin (DCO) is required for contributions to Shirudo. If you submit AI-assisted or AI-generated contributions, you are personally certifying that you have the right to contribute the content under the project's license.
