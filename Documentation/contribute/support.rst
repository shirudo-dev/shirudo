Getting support
===============

shirudo is an open source community project, developed in the open at
https://github.com/shirudo-dev/shirudo.

.. list-table::
   :header-rows: 1
   :widths: 30 70

   * - For
     - Where
   * - Feature requests
     - A GitHub issue that describes the problem the feature would
       solve.
   * - Bug reports and regressions
     - A GitHub issue with what
       :doc:`/operate/troubleshoot/bug-report` asks for.
   * - Security problems
     - Never a public issue. Report them privately, as
       :doc:`/security/reporting` describes.
   * - Community support
     - `shirudo's Zulip <https://shirudo.zulipchat.com>`__.
       Use the `#help channel
       <https://shirudo.zulipchat.com/#narrow/channel/659552-help>`__
       for questions about using shirudo and help from other users.
   * - Ideas and design discussions
     - Use the `#ideas-design channel
       <https://shirudo.zulipchat.com/#narrow/channel/659583-ideas-design>`__.

An issue without activity for 90 days is labeled ``stale`` and closed
after 90 more days, a pull request after 30 days and 30 more. A comment,
or a push to a pull request, takes the label off again. The ``pinned``
label, which a maintainer sets, keeps an issue or a pull request open
regardless.
