Start
=====

Start here if you are new to shirudo. The quickstart builds it, boots a
protected test target in a VM and takes one upatch through its whole
life. The next pages explain the problem shirudo addresses, who it is
for and the path a upatch takes from a kernel fix to a measured load.
The installation page and the quick guides then cover the first tasks:
installing the packages, writing a upatch, publishing a package and
attesting a target, and then the use cases with a backend: live
patching, system hardening and runtime observability.
