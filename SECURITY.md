# Security Policy

Please do not report security vulnerabilities in public issues or discussions.
Instead, use GitHub’s
[**Report a vulnerability**](https://github.com/shirudo-dev/shirudo/security/advisories/new)
feature.

## Project status and scope

shirudo is pre-release and does not currently have stable releases or supported
release branches. We welcome vulnerability reports about the project’s `main`
branch to help harden it before the initial release.

We expect to update this policy as the project matures.
